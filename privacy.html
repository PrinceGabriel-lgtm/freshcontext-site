Privacy and security notes

FreshContext Privacy

This page explains the public FreshContext site, demo, MCP tools, hosted Worker surfaces, data sources, metadata, and contact expectations.

Scope

The FreshContext public site and demo are informational. They explain a freshness-aware context integrity layer for AI systems and show illustrative examples.

FreshContext provides context freshness, confidence, utility, and provenance metadata. It does not determine truth, provide professional advice, or replace domain review.

FreshContext is not legal, medical, tax, or financial advice.

Data Sources

FreshContext MCP tools and reference adapters may contact third-party public data sources depending on the tool used. Examples include public web pages, package registries, public APIs, and market or research data sources documented by the relevant adapter or page.

Users should review the source, timestamp, retrieved time, confidence, freshness score, and provenance fields before relying on any result.

Hosted Worker And Cloudflare

Hosted FreshContext Worker routes may be processed by Cloudflare infrastructure. Cloudflare logs or observability systems may contain request metadata such as route, timing, status, source network metadata, user agent, or error details.

Where implemented, KV, D1, or cache layers may store adapter results, feed records, cache metadata, operational metadata, or historical signal data.

Metadata FreshContext Emits

FreshContext may emit metadata such as source URL, published time, retrieved time, freshness confidence, freshness score, utility values, status, provenance fields, and adapter details where applicable.

Ha-Pri v1 should be treated as a provenance stamp and audit reference. It is not hard tamper enforcement.

Local MCP And Core Usage

Local MCP/Core usage may run on your machine depending on setup. In local configurations, your own environment, MCP client, terminal, logs, and selected adapters determine what is fetched, displayed, or stored locally.

Do not paste secrets, tokens, private logs, customer data, or account credentials into public chats, GitHub issues, demos, screenshots, or logs.

User Data And Telemetry

FreshContext does not currently sell user data.

The public site does not include a payment flow. If telemetry, accounts, billing, or hosted product features are added later, this page should be updated before release.

Contact

For privacy or security questions, use the FreshContext contact page.

Please do not include secrets, tokens, private logs, customer data, or exploit payloads in public issues.
