Legacy

The open-source package.

Before the Stale Answer Audit, FreshContext published an open-source context engine for AI agents. It stays available under its MIT licence, but gets no new development.

What it is

freshcontext-mcp is an MIT-licensed Model Context Protocol server and library. It scores context an agent is about to use (freshness, source and date confidence, provenance) from signals the caller supplies, and returns a reasoned decision about whether to use it. Its latest published version is 0.5.3.

The package is frozen: it receives no new features. The hosted verification endpoint at api.freshcontext.dev is still online today, as published, without new development.

How it relates to the audit

The package scores metadata it is given. It never reads the source. The Stale Answer Audit uses a separate, private engine that reads the live source and checks each claim in an answer against it, with a person reviewing every finding.

Buying an audit doesn't transfer the private engine or its methods. Rights already granted under the MIT licence are unaffected and continue on their own terms.
